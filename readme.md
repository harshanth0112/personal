Blog Portfolio Web Application

🎯 Objective:

Build and configure a Full Stack Blog Portfolio Application by integrating **MongoDB and Firebase** with the provided project. This project will demonstrate database integration, user authentication, and admin access.

📝 Tasks:

1. Project Setup:

- Clone the provided project from GitHub.

- Set up the project in the local development environment.

- Install the required dependencies.

- Configure and run the project successfully.

2. MongoDB Integration:

- Connect the project with MongoDB.

- Create the required database and collections.

- Store and manage blog-related data in MongoDB.

- Fetch and display blog data from the database.

3. Firebase Authentication:

- Connect Firebase with the project.

- Enable Login and Signup functionality using Firebase Authentication.

- Implement user login, signup, and logout.

- Display appropriate authentication success and error messages.

4. Blog Admin Access:

- Create a separate Admin Access for managing blog content.

- Allow authorized admin users to access the Admin Panel.

- Admin should be able to add, edit, view, and delete blog posts.

- Restrict the Admin Panel from unauthorized users.

🧪 Outcome:

A working Blog Portfolio Web Application with MongoDB database integration, Firebase authentication, Login/Signup functionality, and secure Admin Access* for managing blog content.
